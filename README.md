# Calculator
A simple calculator program made with Java.

## What it does
- Add, subtract, multiply, and divide numbers
- Runs in the console
- Made for practice with loops and arrays

## How to run
1. Open the project in any Java IDE like VS Code or IntelliJ
2. Run the `Calculator.main` file
3. Follow the instructions on the screen
